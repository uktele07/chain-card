# 見た目と動きの仕様

戦闘画面の見た目は、持ち主が見本を見て「いったんOK」とした（`docs/samples/style-D3-final.png`）。
**実装はまだ。合図を待つ。** ほかの画面は、この見た目にそろえて見本を出し、了承を取ってから作る。

印の意味: 【決定】＝持ち主が指示・了承した。【案】＝こちらの提案で、持ち主はまだ見ていない。実装前に確かめること。

## 1. 全体の調子【決定】

暗く静かな画面に、金色の細い線と細い文字。敵だけに光を当てる。強い要素は少しだけ置く。

- 手本は、ペルソナ近作の画面まわりと、HD-2D の絵作り。ただし、そのままは真似ない。最初の見本（黒・白・橙赤、斜めの帯と極太の文字を多用）は「多用しすぎ。メリハリが大切」と言われた。
- 極太の文字は、敵の名前の1か所だけ。斜めの形も、敵の名前の帯だけ。
- 見やすさは、ある程度保つ。ただし、それを理由に見た目を控えめにしない。見にくければ持ち主が指摘する。
- 敵の絵は、当面いまの絵のまま（中途半端なドット絵にしない）。

## 2. 色

| 役割 | 色 | 使う場所 |
|---|---|---|
| 地の線と強調【決定】 | 金 `#d8b46a` | 枠の細い線、カードの縁、チェイン、自分のHPのバー、次の攻撃のゲージ、小さな見出し |
| 差し色（ダンジョンごと）【決定】 | 火: 橙赤 `#ff4b1f`　水: 青 `#1fa8ff` | 敵のHPのバー、次の攻撃のダメージの数字、スペルのカード、やけどなどの注意書き |
| 文字 | 白 `#ffffff`、カードの文字は生成り `#f3ead8`、控えめな文字は `#cfc6b4` | |
| 出せないカード | 縁 `#4a4338`、文字 `#5c554a` | |
| 地 | ほぼ黒。カードは `rgba(40,34,28,.92)` から `rgba(10,9,8,.92)` への濃淡 | |

- 金色は全ダンジョン共通、差し色はダンジョンごと、という使い分けで作ってある。**この理解でよいか、持ち主に確かめていない。**
- 討伐（ダンジョンの外）の差し色は未定。敵ごとに変える案がある（以前の背景C案）。

## 3. 文字

| 用途 | 書体 | 太さ・大きさ（960×540 での値） |
|---|---|---|
| 敵の名前【決定】 | Dela Gothic One（極太） | 34 |
| 日本語の文字全般 | Noto Sans JP | 太さ 500。小さな見出しは 10〜11、字間 2〜4 |
| カードの文字、チェインの文字 | Inter Display | 太さ 300（細い）。カード 45、チェイン 36 |
| HP の数字（敵・自分）【決定】 | Inter Display | 太さ 500、大きさ 40。「/ 110」は 14、太さ 400 |
| 次の攻撃 | Inter Display | ダメージ 48（差し色、光らせる）、秒 34（白）。どちらも太さ 300 |

- 書体は見本用に入れただけで、ゲームにはまだ入っていない。Dela Gothic One と Noto Sans JP は SIL Open Font License。Inter も同じ。入れるときに `docs/` へ出典とライセンスを記録する。

## 4. 戦闘画面の配置【決定】

座標は 960×540。見本を作ったスクリプトは `docs/samples/look-gen2.cjs`（`D3-final`）。数値で迷ったら、そちらが正。

| 要素 | 位置と大きさ |
|---|---|
| 敵の絵 | 左上が (650, 176)、大きさ 300。後ろに橙の光 |
| 敵の名前の帯 | 右端から。上 24、高さ 52、幅 316、右へ 12度の斜め。上下に金の細い線。左端は、敵のHPのバーの左端を少し超える程度 |
| 敵の名前 | 右から 30、帯の中。左に小さく「BOSS」などの種別（金） |
| 敵のHP | 「HP」の見出しが右から 30・上 84。数字が上 102。バーが上 148、幅 230、太さ 3、差し色 |
| 次の攻撃 | 中心の x は手札と同じ 480。行の上端 86。左から「NEXT」の札（金の細い枠）、技名、ダメージ、金の縦線、秒。ゲージは上 144、幅 340、太さ 2、金 |
| 手札 | 中心 (480, 368)。カードは 74×83。上下に 90、左右に 98 ずらして十字に置く（△上、○右、✕下、□左） |
| チェイン | 手札の中心。一辺 58 のひし形。金の細い縁、金の文字 |
| アイテム | 左。見出しが (28, 192)。段は下の「リボルバー」 |
| 自分のHP | 左下。見出しが左 30・下から 66（横に、やけどなどの注意書き）。数字が下から 24。バーが下から 14、幅 230、太さ 3、金 |

- ダンジョンの名前は出さない。
- 背景: ぼかしは弱く（柱やレンガが読める程度）、彩度を落として暗くする。敵の周りだけ明るく、画面の縁は暗く落とす。四隅のうち左上と右下に、金の細いかぎ形。
- 背景の絵は見本用の簡易なもの。本番は画像を用意する（`docs/design.md` の「画像生成AIで用意するもの」）。

## 5. アイテムのリボルバー【決定】

- 最上段が選択中。下の段ほど左へずれ、小さく、暗くなる。

| 段 | 左 | 上 | 幅 | 高さ | 文字 | 濃さ |
|---|---|---|---|---|---|---|
| 1（選択中） | 28 | 214 | 204 | 38 | 14 | 100% |
| 2 | 19 | 257 | 190 | 32 | 12.5 | 80% |
| 3 | 10 | 294 | 174 | 26 | 11 | 60% |

- 選択中の段は、金の濃淡と金の縁。右に「R2」。
- L2 を押すと、上から ABC だった並びが BCA になる。最上段が後ろを通って最下段へ回り、2段目が上へ上がる。回転式の弾倉のように、なめらかに動かす。
- 4コマの図: `docs/samples/style-D-revolver.png`。

動きの細部【案】:
- 時間は 0.22秒。動き出しと止まり際をなめらかに。
- 後ろへ回る段は、途中で左へ 34 寄り、幅が 30 縮み、濃さが 25% まで落ち、ほかの段の後ろに隠れる。
- 動いている間も入力を受ける。続けて押されたら、いまの位置から次の回転を始める（順番待ちにしない）。
- 使用済みのアイテムは、暗い表示で輪に残す。L2 では飛ばす（1回の動きで2段ぶん回る）。使える物が1つ以下なら回らず、小さく揺れる。
  - いまのルール（`battle.ts` の `cycleItem`）も、使用済みを飛ばす。表示の扱いだけが新しい。

## 6. カードの傾き【決定】

- カードは少しだけ傾ける。角度は −2〜+2度。
- 入れ替えのたびに、角度をランダムに変える。

## 7. 動きの仕様【案】

共通の約束:
- **演出は入力を止めない**【決定】。どの動きの最中でも、ボタンは効く。
- 長さは 0.15〜0.25秒。動き出しは速く、止まり際をゆっくり。
- 既にある演出（敵の揺れ、被弾の赤い光、強い攻撃の赤い縁、音）は残す。

| 場面 | 動き |
|---|---|
| 戦闘の開始 | 敵の名前の帯は右から、アイテムは左から、手札は下から、0.25秒で入る。0.04秒ずつずらす |
| カードを出す | 出したカードが、チェインへ向かって 0.12秒で縮みながら消える。チェインの文字が 1.3倍から戻る（0.18秒） |
| 出せないカードを押す | そのカードが左右に 0.15秒ふるえ、縁が一瞬だけ赤くなる |
| キープ | カードが 4 上がり、縁が金で太くなる。解除で戻る |
| 入れ替え | いまの手札が 0.1秒で下へ沈んで消え、新しい手札が下から 0.15秒で入る（0.03秒ずつずらす）。このとき傾きを変える |
| チェインが上がる | ひし形が外へ光り、縁の光が 0.2秒で広がって消える |
| チェインが切れる | ひし形の光が消え、文字が 0.2秒で下へ落ちて薄くなる |
| 次の攻撃 | ゲージが進む。「！」の攻撃は、ダメージの数字とゲージが赤くなり、ゆっくり明滅。残り 1.5秒からは、0.5秒ごとに秒の数字が脈打つ（既にある音と合わせる） |
| 敵に当てる | 敵が揺れる。数字が跳ねて出る。敵のHPのバーは、減った分が白く残り、0.4秒かけて縮む |
| S を当てる | 敵の絵だけ 0.08秒止め、画面を揺らし、白く光らせる（操作は止めない） |
| 攻撃を受ける | 赤い光。自分のHPの数字がふるえ、バーは減った分が白く残って縮む |
| 討伐 | 敵が白く光ってから、0.4秒で下へ沈んで消える。敵の名前の帯が右へ出ていく。結果の枠が 0.25秒で入る |
| 画面の切り替え | 0.2秒で、横へ少し動きながら入れ替わる。カーソルの移動は 0.1秒 |

  - 極太は画面の題（「行き先」）の1か所だけ。
  - 右は絵だけ（説明文を置かない、という以前の指示のまま）。金の二重の細い枠、左端に差し色の線。
  - 操作の案内は右下に小さく。ボタン名は金の細い枠。
  - 1案しか出していない。約束の「違いのある3案」には足りていない。
- 金色と差し色の使い分け（2章）。
- 戦闘画面に載せきれない情報の扱い: アイテムの説明文、強化薬や時の砂の残り時間、無敵（テスト用）の表示、ゲームパッドの状態の案内、開始前の「START」。見本には入っていない。
