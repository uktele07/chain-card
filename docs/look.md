# 見た目と動きの仕様

戦闘画面の見た目は、持ち主が見本を見て「いったんOK」とした（`docs/samples/style-D3-final.png`）。
そのあと、載せきれなかった情報を足し、次の攻撃の行を直した版も了承を得た。戦闘中は `style-D6B-fight.png`、開始前は `style-D4-start.png`（4章の後半）。
**戦闘画面（開始前・戦闘中）は実装済み（2026-11-17、段階1）。** 実装で決めた細部は10章。ほかの画面は、この見た目にそろえて見本を出し、了承を取ってから作る。

印の意味: 【決定】＝持ち主が指示・了承した。【案】＝こちらの提案で、持ち主はまだ見ていない。実装前に確かめること。

## 1. 全体の調子【決定】

暗く静かな画面に、金色の細い線と細い文字。敵だけに光を当てる。強い要素は少しだけ置く。

- 手本は、ペルソナ近作の画面まわりと、HD-2D の絵作り。ただし、そのままは真似ない。最初の見本（黒・白・橙赤、斜めの帯と極太の文字を多用）は「多用しすぎ。メリハリが大切」と言われた。
- 極太の文字は、敵の名前の1か所だけ。斜めの形も、敵の名前の帯だけ。
- 見やすさは、ある程度保つ。ただし、それを理由に見た目を控えめにしない。見にくければ持ち主が指摘する。
- 敵の絵は、当面いまの絵のまま（中途半端なドット絵にしない）。

1. このページではゲームパッドを使えない（ブラウザが対応していない、または枠の中のページで禁止されている。claude.ai の共有ページなど）。ただし、つながったパッドが見つかれば出ない。

## 7. 動きの仕様【案】

共通の約束:
- **演出は入力を止めない**【決定】。どの動きの最中でも、ボタンは効く。
- 長さは 0.15〜0.25秒。動き出しは速く、止まり際をゆっくり。
- 既にある演出（敵の揺れ、被弾の赤い光、強い攻撃の赤い縁、音）は残す。

| 場面 | 動き |
|---|---|
| 戦闘の開始 | 敵の名前の帯は右から、アイテムは左から、手札は下から、0.25秒で入る。0.04秒ずつずらす |
| カードを出す | 出したカードが、チェインへ向かって 0.12秒で縮みながら消える。チェインの文字が 1.3倍から戻る（0.18秒） |
| 出せないカードを押す | そのカードが左右に 0.15秒ふるえ、縁が一瞬だけ赤くなる |
| キープ | カードが 4 上がり、縁が金で太くなる。解除で戻る |
| 入れ替え | いまの手札が 0.1秒で下へ沈んで消え、新しい手札が下から 0.15秒で入る（0.03秒ずつずらす）。このとき傾きを変える |
| チェインが上がる | ひし形が外へ光り、縁の光が 0.2秒で広がって消える |
| チェインが切れる | ひし形の光が消え、文字が 0.2秒で下へ落ちて薄くなる |
| 次の攻撃 | ゲージが進む。「！」の攻撃は、ダメージの数字とゲージが赤くなり、ゆっくり明滅。残り 1.5秒からは、0.5秒ごとに秒の数字が脈打つ（既にある音と合わせる） |
| 敵に当てる | 敵が揺れる。数字が跳ねて出る。敵のHPのバーは、減った分が白く残り、0.4秒かけて縮む |
| S を当てる | 敵の絵だけ 0.08秒止め、画面を揺らし、白く光らせる（操作は止めない） |
| 攻撃を受ける | 赤い光。自分のHPの数字がふるえ、バーは減った分が白く残って縮む |
| 討伐 | 敵が白く光ってから、0.4秒で下へ沈んで消える。敵の名前の帯が右へ出ていく。結果の枠が 0.25秒で入る |
| 画面の切り替え | 0.2秒で、横へ少し動きながら入れ替わる。カーソルの移動は 0.1秒 |

## 10. 段階1の実装で、こちらが決めた細部【案】

見本に無かった状態や、見本どおりにできなかった所。持ち主はまだ見ていない。違えば直す。

- 敵の名前の左の種別: ダンジョンのボス「BOSS」、中ボス「GUARD」、雑魚は出さない。討伐はランクの漢字（弱・並・強・魔・神）。

- チェインの残り時間: 以前の輪の弧の代わりに、ひし形の外側の金の細い線が減っていく。残り3分の1で赤。
- 次のアタックにかかる効果（スペルの印）: チェインの右上（手札の間のすき間）に、差し色の小さな札で出す。
- キープ: カードが4上がり、縁が金で太くなり、右上に「KEEP」。
- 入れ替え中: 空いた枠の下から金が満ちる。チェインの見出しが「入れ替え中」。ミスは赤い「✕」と「ミス」、斧などの待ちは「構え」。
- スタン中: 技名の位置に「スタン中」（控えめな色）。ダメージと秒は薄く出したまま。
- 自分の HP が3割以下: 数字を差し色にする（バーは金のまま）。
- アイテムの選択中の段の右: ゲームパッドなら「R2」、キーボードなら「E」。以前あった「L2 で切り替え」の案内は出さない（操作説明にある）。
- アイテムの説明が長いときは2行まで折り返し、その下に効果を詰めて並べる。
- 開始前の中央: ゲームパッドなら「○」、キーボードなら「Enter」。操作の案内のボタン名も、キーボードでは「Backspace」「Esc」。
- 見本にあった、画面全体の細かいざらつき（ノイズ）は入れていない。Canvas の上で重ねると重いため（`docs/ui-migration.md` の3章）。

- 敵の揺れ、被弾の赤い光、強い攻撃の赤い縁、跳ねる数字は、以前のまま（Canvas）。跳ねる数字の書体は、まだ以前のもの。

## 11. 行き先の画面の実装で、こちらが決めた細部【案】

2026-11-17 に実装（段階3を先に行った）。見本はダンジョンの一覧だけだったので、討伐の一覧は同じ作りにそろえた。

- 右の枠の絵: 見本と同じく、神殿の広間を切り出した絵（たいまつと溶岩を光らせる）。以前の神殿の外観の絵は使っていない。準備中のダンジョンは、枠の中に「準備中」だけ。
- 討伐の一覧: 行の頭の印はランクの漢字。右に自己ベストの秒と、ランク（金の細い丸）。まだなら「未討伐」、出ていない敵は「？？？」と「未出現」。
- 討伐の右の枠: 敵の名前（極太にしない）、HP、敵の絵、攻撃パターン（「！」の技は赤）、1巡の秒と合計、戦利品。討伐するまでは秒とダメージを「？？？」にする（以前と同じ）。
- 差し色は火と同じ橙赤（討伐の差し色は未定のため）。
